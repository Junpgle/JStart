# JStart Edge 扩展安装说明

## 安装步骤

1. 打开 Edge 浏览器
2. 在地址栏输入 `edge://extensions/` 并回车
3. 打开左下角的"开发人员模式"开关
4. 点击"加载解压缩的扩展"按钮
5. 选择 `edge-extension` 文件夹
6. 扩展安装完成

## 使用说明

安装后，每次打开新标签页都会显示 JStart 页面。

## 卸载方法

1. 打开 `edge://extensions/`
2. 找到 "JStart New Tab" 扩展
3. 点击"删除"按钮

## 注意事项

- 扩展使用 iframe 嵌入 JStart 页面
- 需要网络连接才能加载 JStart
- 如果 JStart 服务器不可用，新标签页将显示空白
